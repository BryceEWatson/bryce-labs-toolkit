# Render Final Output Files

You are rendering final output files from the collection of promoted stories.

## Input Format

You will receive `stories.jsonl` containing all promoted stories:

```json
{
  "storyId": "story-abc123",
  "title": "Memory Leak from Unreleased ObjectURLs",
  "category": "bug",
  "tags": ["memory", "cleanup", "react"],
  "synopsis": "...",
  "narrative": "## Memory Leak...\n\n[full markdown]",
  "quotes": [
    {
      "text": "The memory leak is caused...",
      "attribution": "assistant",
      "provenance": {
        "pointer": "session-001/45#abc123"
      },
      "context": "..."
    }
  ],
  "claims": [...],
  "score": 0.82,
  "createdAt": "2026-02-07T14:22:00Z"
}
```

## Task

Generate three output files:

1. **stories.md** - Full narrative document with all stories, quotes, and provenance
2. **digest.md** - Quick summary table for rapid scanning
3. **index.json** - Machine-readable index of all stories

## About Story Mining

This document was generated by the story-miner skill, which analyzes Claude Code
session logs to extract interesting development stories. Each story is:

- **Grounded**: Quotes traced to specific session events via provenance pointers
- **Validated**: Structural checks ensure context, discovery, and resolution
- **Scored**: Narrative value scored 0.0-1.0 based on signal strength and teaching value
- **Deduplicated**: Similar incidents merged to avoid redundancy

### Provenance Pointers

Format: `{sessionId}/{lineIndex}#{contentHash16}`

- **sessionId**: Unique identifier for the Claude Code session
- **lineIndex**: Line number in the session log (0-indexed)
- **contentHash16**: First 16 chars of SHA-256 hash of event content

Provenance pointers allow verification of every quote against source material.

---

## Sources

- **Preprocessor version:** {version}

- **Story-miner version:** {version}
- **Generated:** {ISO-8601 timestamp}

### Formatting Rules

- Stories sorted by score (descending)
- Slugs generated from titles (lowercase, hyphen-separated, no special chars)
- Quotes formatted as blockquotes with attribution and pointer
- Claims formatted as bullet list with evidence pointers
- All timestamps in ISO-8601 format
- Proper markdown escaping (backticks for code terms, etc.)

### Field Specifications

**Root level:**
- **version**: Integer version number (1)
- **generatedAt**: ISO-8601 timestamp when index was generated
- **metadata**: Summary statistics object
- **stories**: Array of story objects (sorted by score descending)
- **categories**: Object mapping category name to count
- **tags**: Object mapping tag to count (top 50 by frequency)
- **topStories**: Top 10 stories by score

**Metadata object:**
- **storyCount**: Total published stories
- **candidatesEvaluated**: Total candidates scored
- **candidatesPromoted**: Candidates with status "promoted"
- **candidatesRejected**: Candidates with status "rejected"
- **sessionsAnalyzed**: Unique sessions processed
- **dedupeClusters**: Number of deduplication clusters
- **totalQuotes**: Sum of all quotes across stories
- **totalClaims**: Sum of all claims across stories
- **dateRange**: Object with earliest and latest createdAt timestamps
- **scoreStats**: Object with min, max, mean, median scores

**Story object:**
- **storyId**: Story identifier
- **title**: Story title
- **category**: Category string
- **tags**: Array of tags
- **score**: Numeric score (0.0-1.0)
- **quoteCount**: Number of quotes in story
- **claimCount**: Number of claims in story
- **createdAt**: ISO-8601 timestamp
- **dedupeClusterId**: Cluster ID if merged (or null)
- **mergedFrom**: Array of candidate IDs merged into this story

## Processing Instructions

1. **Load all stories** from `stories.jsonl`
2. **Calculate statistics**:
   - Count stories, quotes, claims
   - Count candidates from mergedFrom arrays
   - Compute score stats (min, max, mean, median)
   - Aggregate categories and tags
   - Determine date range
3. **Generate stories.md**:
   - Sort stories by score (descending)
   - Render each story with full narrative, quotes, claims
   - Include metadata section at end
4. **Generate digest.md**:
   - Create summary table sorted by score
   - Group stories by category
   - Extract top insights (one per story)
   - Show top 20 tags by frequency
5. **Generate index.json**:
   - Build metadata object
   - Build stories array (sorted by score)
   - Build categories object
   - Build tags object (top 50)
   - Build topStories array (top 10)
